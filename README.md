# Powerbi_project
End-to-end data analytics project featuring interactive Power BI dashboards. Utilizes [SQL / Python / DAX] for data cleaning, transformation, and modeling, uncovering key performance metrics, customer behavior insights, and regional revenue trends to drive executive decision-making.
Use this script to clean your raw data (e.g., handling missing values, standardizing columns, and exporting a clean CSV ready for Power BI).
